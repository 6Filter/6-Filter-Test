## M3. The reliability fix for the AI calls (the most valuable change; it does not touch scoring)
Today `lib/callAnthropic.js` sends one request with no timeout, no automatic retry and no limit on simultaneous calls, and any non-OK answer throws at once. Fix it (check every other place that calls the API directly too):
1. **Retry with exponential backoff and jitter** on HTTP 429, 529 and 500 to 503, and on network errors (`fetch failed`, `ECONNRESET`, `ETIMEDOUT`): at most 4 attempts, honour `retry-after` when present, cap the total waiting at about 90 seconds, and keep the existing error messages when it finally fails.
2. **Never retry** 400, 401, 403, the billing or credit-exhausted error, or a request the provider rejects: those fail at once as today.
3. **A timeout** on every call (an `AbortController` timer that is always cleared; about 240 seconds when web search is on, 90 seconds otherwise); a timeout counts as retryable once.
4. **A concurrency gate** (a semaphore with a first-in-first-out queue) limiting simultaneous Anthropic calls on the server to a configurable number (default 4), with a queue-wait timeout and a clear message if it expires.
5. **Accounting:** a retried call is billed and counted **once** (a failed attempt must not double-count usage or cost).
6. **No secret in any log**; log only counts and attempt numbers.
7. An unfinished step must still end as today: "Research failed, retry", no score, the existing per-step "Screen again". Never produce a result from a failed call.
**Tests, against a fake Anthropic server (no real key needed):** 429 then 200 succeeds; 529 twice then 200 succeeds; a timeout then 200 succeeds; a persistent 429 fails cleanly after the maximum attempts with the existing message and the "Screen again" state; 400, 401 and the credit error are not retried; `retry-after` is honoured; 10 simultaneous calls with a limit of 4 never exceed 4 in flight and all finish; a retried success is counted once; no secret in the output. **Run the logic lock and the scoring tests: nothing in the locked set may change.** Commit it on its own branch.
